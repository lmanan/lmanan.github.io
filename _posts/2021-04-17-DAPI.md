Two family of approaches currently exist for making neural networks more interpretable - *feature attribution* highlight the features which influence the output classification and *counterfactual* methods present the user with a minimally modified input sample that leads to a different output classification.

[Eckstein _et al, 2023_](https://link.springer.com/chapter/10.1007/978-3-031-25069-9_27) provide a method which translates a real image $$\textbf{x}_{R}$$ into a counterfactual image $$\textbf{x}_{C}$$ of a different class. Additionally, the authors are able to find an attribution map by processing the paired images $$\textbf{x}_{R}$$ and $$\textbf{x}_{C}$$. The discriminative attribution method searches for the minimal mask, such that copying the most discriminative parts of the real image $$\textbf{x}_{R}$$ into the counter factual $$\textbf{x}_{C}$$ leads it to be classified as the same class as $$\textbf{x}_{R}$$.

While summarizing the previous work done for counter-factual generation, the authors state that:

>"... a counterfactual is found as a result of an optimization aiming to maximize output differences while minimizing input differences between the real image and the counterfactual image."

Put in equation, this is equivalent to:

$$
\textbf{x}_{C} = \text{argmin}_{\textbf{x}} L_{i} (\textbf{x}_{R}, \textbf{x}) - L_{o}(f(\textbf{x}_{R}), f(\textbf{x}))
$$  

But this optimization is tricky since there are two competing loss terms. Eckstein _et al_, 2023 avoid the input similarity loss term and enforce similarity between the input image and the counterfactual image, in a post-hoc fashion. 

Currently, to find the counterfactual attribution map between each pair of classes one has to train an individual model. Also, there is one counterfactual image which is generated per input image (and not a distribution of counterfactual images). These are potential weaknesses which could be addressed in a future work.
