(From [Wang et al, 2019](https://arxiv.org/abs/1904.01828))
>"Our intuition resides on the observation that visual tracking can be performed in both the forward and backward manners. Initially given the target object annotated on the first frame, we can track the target object forward in the subsequent frames. When tracking backward, we use the predicted location in the last frame as the initial target annotation and track it backward towards the first frame. The estimated target location in the first frame via backward tracking is expected to be identical with the initial annotation. "
