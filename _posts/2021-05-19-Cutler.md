From [Wang et al, 2023](https://arxiv.org/abs/2301.11320)


>"We leverage the property of self supervised models to discover objects without supervision and amplify it to train a model without any human labels."

How do they amplify this ability?

>"Cutler first uses our proposed MaskCut approach to generate coarse masks for multiple objects in an image, and thne learns a detector on these masks using our robust loss function."

How does MaskCut work? How do you learn a detector on these masks?

>"Our key insight is that simple probing and training mechanisms can amplify the innate localization ability of self supervised models."

What does simple probing and training mechanism imply?

>"Prior work shows that a self supervised vision transformer can automatically learn patch wise features that detect a single salient object in an image."

What does object saliency mean in this context? 
This was shown by the paper - An image is worth 16 x 16 words.

>"Compared to the previous SOTA, FreeSOLO with a backbone of ResNet 101, Cutler with a backbone of Resnet 50 provides strong gains on all benchmarks."

How does FreeSOLO work?

>"We construct a fully unconnected graph via representing each image as a node. Each pair of nodes is connected by  edges with weights Wij that measure the similarity of the connected nodes."

Here each image refers to a single image patch? What do indices i and j go from and to? What exactly is D?

>"where D is a N x N diagonal matrix and W is a N x N symmetric matrix."

Okay!

>"Ncut minimizes the cost of partitioning the graph into two subgraphs i.e. a bipartition, by solving a generalized eigen value system for finding the eigen vector x that corresponds to the second smallest eigenvalue" 


Why do we use the second smallest eigen value and corresponding vector? Why not use the smallest?

>"To determine which group corresponds to the foreground, we make use of two criteria: 1) intuitively the foreground patches should be more prominent than background patches. Therefore the foreground mask should contain the patch corresponding to the maximum absolute value in the smallest eigen vector."

What is the dimensionality of the eigen vector? 

>"The foreground set should contain less than two of the four corners."

That makes sense!
