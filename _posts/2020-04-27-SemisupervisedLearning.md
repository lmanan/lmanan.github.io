(From [Kingma et al](https://arxiv.org/abs/1406.5298), 2014)
>"Amongst existing approaches,  the simplest algorithm for semi-supervised learning is based on a self-training scheme (Rosenberg et al., 2005) where the the model is bootstrapped with additional labelled data obtained from its own highly confident predictions; this process being repeated until some termination condition is reached.  These methods are heuristic and prone to error since they can reinforce poor predictions. ... Graph-based methods are amongst the most popular and aim to construct a graph connecting similar observations; label information propagates through the graph from labelled to unlabelled nodes by finding the minimum energy (MAP) configuration (Blum et al., 2004; Zhu et al., 2003). Graph-based approaches are sensitive to the graph structure and require eigen-analysis of the graph Laplacian, which limits the scale to which these methods can be applied – though efficient spectral methods are now available (Fergus et al., 2009)."

Kingma and colleagues address the problem of classification when only a small subset of data has corresponding class labels. They propose a probabilistic approach rooted in variational inference to solve this.

In the *M1 Model*, the authors propose using all the data (labeled and unlabeled) to learn the approximate posterior function $$q_{\phi} (z \vert x) $$ which is parameterized by weights $$\phi$$. This model provides an embedding or feature representation of the data. Using these features, a separate classifier is thereafter trained. Approximate samples from the posterior distribution over the latent variables $$ p(z \vert x) $$ are used as features to train a classifier that predicts class labels $$ y$$.

In the *M2 Model*, the authors propose that the data is generated by a continuous latent variable $$z$$ and a discrete latent class label $$y$$. Predictions for any missing labels are obtained from the inferred posterior distribution $$p_{\theta} (y \vert x ) $$.

A detailed explanation of the theory is provided in [this](http://bjlkeng.github.io/posts/semi-supervised-learning-with-variational-autoencoders/) blog post. This publication makes me wonder how often are variational auto encoders used for data imputation.
